In the conversation

What every player follows

  • Narration, dialogue, choices, and open-ended actions
  • Visible rolls, modifiers, DCs, outcomes, and rulings
  • Compact character, inventory, spell, and objective status
  • Static generated scenes shown in the same conversation when image generation is available

With a writable local Codex workspace

What the desktop table adds

  • Campaign files, checkpoints, journals, clues, NPCs, factions, and mechanical state
  • A chronological visual gallery that survives long sessions
  • Interactive 360 POV viewers for spatial exploration
  • An optional original soundtrack selected for the current scene

Look around when space matters.

In local Codex play, a 360 image opens as a photosphere. Music never starts by default; the speaker choice is voluntary and remembered by later viewers.

Designed for the real play surface

Codex is not behind the game. It is where the game happens.

The campaign is original each time. A creative conception pass establishes environment, community, material conflict, threat, relationships, tone, and campaign promise before the first scene.

The rules remain inspectable. Questforge ships with an offline English and Spanish primer and can optionally index the public 5E SRD 5.2.1 with the player's consent.

The visuals remain accountable. Text and structured state decide what happened. Images support imagination; they do not silently rewrite positions, injuries, equipment, or outcomes.

Source installation

Bring a new world into Codex.

Add the public repository as a Questforge marketplace, install the plugin from Codex, then start a new task and ask to play.

codex plugin marketplace add adrianmelic/codex-questforge
