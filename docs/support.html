Useful Details

Include the Questforge version, OpenAI surface, operating system, the command or prompt that failed, and a minimal error excerpt.

Remove character details, campaign spoilers, private paths, generated images, credentials, and personal information before posting publicly.

For a rules disagreement, say whether you are asking about the bundled core primer, the indexed SRD 5.2.1, or a table ruling. Questforge records recurring table rulings so a campaign can remain consistent when the full SRD is silent or ambiguous.
