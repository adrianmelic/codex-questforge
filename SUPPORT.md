# Questforge Support

Questforge is maintained by Adrián Melic.

- Product page: https://adrianmelic.com/questforge
- Setup and play guide: https://github.com/adrianmelic/codex-questforge#start-playing
- Bug reports and feature requests: https://github.com/adrianmelic/codex-questforge/issues
- Email: info@adrianmelic.com

When reporting a problem, include the Questforge version, OpenAI surface, operating system, the command or prompt that failed, and a minimal error excerpt. Remove character details, campaign spoilers, private paths, generated images, credentials, and personal information before posting publicly.

For a rules disagreement, say whether you are asking about the bundled core primer, the indexed SRD 5.2.1, or a table ruling. Questforge records recurring table rulings so a campaign can remain consistent even when the full SRD is silent or ambiguous.
